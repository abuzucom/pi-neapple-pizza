# Contributing

## Setup and validation

Canonical agents policy overrides conflicting upstream pi instructions.
Obtain required consent before dependencies, scripts, tests, builds, or protected writes.
PyYAML 6.0.3 supplies the canonical YAML checkers.

Run `python scripts/run_tests.py` for the adopted policy suite.
Run `make lint PYTHON=python` for policy lint.
Run adoption, launcher, synchronization, and shared-integrity checks.

## Pi development reference

The pi runtime has not entered this repository.
See `docs/pi-architecture.md` for package-specific reference commands.
Use the faux provider for later coding-agent suite tests.
Preserve exported APIs, CLI flags, tool schemas, extension events, and session formats.

## Change workflow

1. Run strict branch preflight.
2. Obtain act-specific authorization for gated acts.
3. Add and run a failing behavioral test for executable changes.
4. Implement the approved change without weakening tests or checks.
5. Run required validation.
6. Update versioned changelog and applicable drift entries.
7. Verify operator identity before committing.
8. Commit only intended files.
9. Create a draft pull request through trusted tooling.

Use ASCII American English prose and UTF-8 LF files.
Preserve the adopted commit format and exact operator attribution.
Keep secrets out of commits and audit records.
Never rewrite published history without required consent.
